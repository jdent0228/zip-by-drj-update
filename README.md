# zip by Dr.J — 자동 업데이트 피드

**zip by Dr.J** — 한글 파일명이 깨지지 않는 macOS 압축/해제 앱 · 문의: jdent0228@gmail.com

이 저장소는 앱 내 자동 업데이트(차등)용 피드입니다.
- `manifest.json` — 최신 버전과 파일별 SHA256
- Releases — 구성 파일 자산 (바뀐 파일만 내려받습니다)

설치 파일은 [zip-by-drj-releases](https://github.com/jdent0228/zip-by-drj-releases/releases/latest)에서 받으세요.
